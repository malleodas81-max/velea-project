# VELÉA — премиальный fashion-магазин (концепт для портфолио)

Чистые HTML, CSS и JavaScript без зависимостей и без внешних запросов. Интерфейс и контент — на русском языке, цены — в рублях (₽).
Бренд, товары, отзывы и бутик вымышлены. **Магазин демонстрационный: оплата не проводится, заказы никуда не отправляются.**

## Что работает
Каталог, категории и коллекции, фильтры (категория, размер, цвет, цена, наличие), сортировка, поиск (с учётом «ё»), страница товара с галереей и выбором цвета и размера, избранное, корзина (количество, удаление, промокоды `WELCOME10`, `VELEA15`, `FREESHIP`, порог бесплатной доставки), пошаговое демо-оформление заказа, страница заказа и «Аккаунт» (демо). Корзина, избранное и демо-заказы хранятся в `localStorage` браузера и сохраняются после перезагрузки страницы.

## Маршруты (чистые URL)
`/` · `/shop` · `/new` · `/search?q=` · `/collections` · `/collections/<slug>` · `/product/<slug>` · `/wishlist` · `/cart` · `/checkout` · `/order/<id>` · `/account` · `/campaigns` · `/campaigns/<slug>` · `/about` · `/contact` · `/faq` · `/policies/<slug>`

## Локальный запуск
```
npm start          # локальный сервер (адрес появится в консоли, по умолчанию порт 8080)
npm run build      # копирует сайт в dist/ и подставляет публичный адрес
npm run preview    # сервер для папки dist/
npm run prerender  # (по желанию) пересобирает статические страницы и sitemap.xml
```
Сайт использует History API, поэтому открывать `index.html` двойным щелчком нельзя — нужен `npm start` (в Windows — `start.bat`).
Требуется Node.js 18+. Для `npm run prerender` нужны Python 3, `pip install playwright` и `playwright install chromium`.

## Где что лежит
- `data/products.js` — каталог (15 изделий), `data/content.js` — коллекции, кампании, FAQ, условия, таблица размеров.
- `js/store.js` — корзина, избранное, заказы, промокоды, расчёт итогов и формат цен `VEL.fmt`.
- `js/pages/*.js`, `js/components/*.js` — страницы и интерфейсные строки.
- `index.html` — оболочка (шапка, меню, подвал, метаданные). После правок контента запускайте `npm run prerender`.
- `assets/fonts/` — шрифты SIL OFL. Латиница: Bodoni Moda и Inter; кириллица: Playfair Display (заголовки) и Inter (текст).

## Цены
В каталоге числовые значения цен сохранены как были; изменён только формат отображения — теперь это рубли (`1 290 ₽`). Если нужны реалистичные рублёвые цены, измените значения в `data/products.js`, порог `FREE_FROM`, стоимость доставки `SHIP` и пороги промокодов в `js/store.js`, а также суммы в текстах (`data/content.js`, `index.html`, `js/pages/home.js`, `js/pages/product.js`). Расчёт НДС в итогах — демонстрационный.

## Деплой на Vercel
1. **GitHub.** Создайте репозиторий и загрузите папку проекта (`git init`, `git add .`, `git commit -m "VELEA"`, `git remote add origin <адрес>`, `git push -u origin main`). Содержимое папки лежит в корне репозитория либо в подпапке `VELEA/`, если репозиторий общий.
2. **Импорт.** В Vercel: Add New → Project → выберите репозиторий.
3. **Root Directory.** Корень репозитория или `VELEA`, если проект лежит в подпапке.
4. **Build Settings.** Framework Preset — Other. Build Command — `node scripts/build.js` (уже указана в `vercel.json`). Output Directory — `dist`. Install Command — по умолчанию (зависимостей нет).
5. **Environment Variables.** Не обязательны. `SITE_URL` (например, `https://ваш-домен.ru`) нужна только для собственного домена: от неё зависят canonical, Open Graph и `sitemap.xml`. Без неё берётся адрес проекта на Vercel (`VERCEL_PROJECT_PRODUCTION_URL`).
6. **Проверка деплоя.** Откройте главную, затем напрямую `/shop`, `/product/halden-trench`, `/cart`, `/checkout`; обновите страницу на внутренних маршрутах; добавьте товар в корзину и дойдите до демо-заказа; откройте несуществующий адрес (страница 404 с кодом 404); проверьте `/sitemap.xml` и `/robots.txt`: в них должен быть ваш адрес, а не `example.com`.

## Ограничения
- Нет сервера, базы данных и платёжной интеграции: оформление заказа, аккаунт, рассылка и форма обратной связи демонстрационные.
- Отзывы и рейтинги на страницах товаров демонстрационные и помечены как такие; в микроразметку они не выводятся.
- Это концепт для портфолио, а не готовый к коммерческой эксплуатации магазин.
